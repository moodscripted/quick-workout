# Quick Workout

A simple Android workout timer with voice coaching that plays over your own music.
Kotlin and Jetpack Compose, no network access, no tracking, no account.

- Seven built-in workouts plus your own custom ones
- Voice cues through the phone's text-to-speech engine, ducking other audio
- History, personal bests, weekly goal, body-weight log, backup and CSV export

## Build
Open the project in Android Studio and run the `app` configuration. Requires JDK 17.

## Privacy
Everything is stored on the device. Nothing is sent anywhere. Uninstalling the app removes all data.
